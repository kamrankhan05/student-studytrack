# 📚 StudyTrack

A modern student task management application built with **HTML, CSS, Vanilla JavaScript, and Supabase**.

StudyTrack helps students organise assignments, monitor deadlines, and stay productive through a clean and intuitive interface.

---

## ✨ Features

- 🔐 User Authentication (Sign Up & Login)
- ✅ Create, Edit, Delete Tasks
- 📅 Due Date Management
- 📚 Subject Categorisation
- 📝 Task Notes
- 🚦 Priority Levels (Low, Medium, High)
- ✔️ Task Status Tracking
- 🔍 Search & Filter Tasks
- 📊 Dashboard Statistics
- ☁️ Cloud Database with Supabase
- 📱 Responsive Design

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Supabase
- Google Fonts
